# template-general

General-purpose project template for Horizon-Nova.

## Included
- `docs/standards/` — Coding standards, testing guidelines, task checklist
- `GitPush.bat` — Backup, pull, and push automation
- `.github/workflows/sync-docs.yml` — Auto-sync latest standards on push

## Usage
Create a new repository using this template. Standards docs will stay updated automatically on every push.
